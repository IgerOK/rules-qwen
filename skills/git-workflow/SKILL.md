# 🍏 Skill: Git-Workflow Scenario

## Когда активировать
- При старте работы в новой директории.
- По прямому запросу пользователя на фиксацию изменений или настройку Git.

## Алгоритм выполнения:
1. **Проверка окружения:** Выполни `git --version` в терминале. Если Git не найден в Windows-окружении, запроси установку через нативный вызов: `cmd.exe /c winget install Git.Git`.
2. **Инициализация:** Если папка не является репозиторием, выполни `git init`.
3. **Изоляция (.gitignore):** Проверь наличие `.gitignore`. При отсутствии — создай его. Обязательно добавь туда системный хлам (`.DS_Store`, `Thumbs.db`), папки кэша ИИ (`.qwen/`, `.opencode/`) и локальные секреты (`.env`, `auth.json`).
4. **Конфигурация пользователя:** Сверь глобальные параметры `user.name` и `user.email`. Если они пусты, вежливо запроси данные у пользователя в чате.
5. **Атомарные коммиты:** После каждого успешного изменения файлов выполняй цепочку `git add <file>` + `git commit -m "feat/fix: description"`.
6. **Ограничение сети:** Выполнять `git push` или привязку `git remote add` ЗАПРЕЩЕНО, пока пользователь сам явно не напишет об этом в чате.
