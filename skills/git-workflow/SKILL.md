# git-workflow

Проверка и настройка Git перед началом работы с кодом: установка Git (при
отсутствии), инициализация репозитория, `.gitignore`, настройки пользователя,
статус, коммит после изменений; remote и пуш — только по отдельной просьбе
пользователя.

## Когда использовать

- Начало работы с новым проектом.
- Проект ещё не инициализирован как git-репозиторий.
- Пользователь просит настроить Git или сделать коммит.

## Шаги

1. **Проверить наличие Git** — `git --version`. Если нет — предложить установку
   (Windows: `winget install Git.Git`).
2. **Инициализация** — если папка не репозиторий, `git init`.
3. **`.gitignore`** — создать, если нет. Добавить ОС-хлам и служебные каталоги
   (см. `.gitignore` в этом проекте).
4. **Настройки пользователя** — если не заданы, предложить:
   `git config --global user.name "<USER>"` и
   `git config --global user.email "email@example.com"`.
5. **Статус** — `git status` перед работой.
6. **Коммит** — после каждого изменения: `git add` + `git commit`.
7. **Remote/push** — только по явной просьбе пользователя.

## Ограничения

- Remote и push — только по отдельной просьбе.
- Не менять чужие настройки без запроса.
