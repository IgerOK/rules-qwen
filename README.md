# 🛠️ rules-qwen

Единый источник истины для настройки и урезонивания ИИ-агента в **Qwen Code Desktop** и **OpenCode**. Адаптация конфигурации [rules-zed](https://github.com) под специфику работы движка Qwen и окружения Windows.

## 📦 Состав репозитория

| Файл / Папка | Назначение |
| :--- | :--- |
| `rules-Qwen.md` | **Канон-инструкция (Master Prompt).** Содержит адаптивные профили экономии токенов и handoff-протокол. |
| `AGENTS.md` | **Контекст проекта.** Перехватывает управление на чистой машине и запускает развертывание. |
| `skills/git-workflow/SKILL.md` | **Сценарий Git.** Безопасная локальная фиксация кода (авто-пуш запрещен). |
| `skills/project-doctor/SKILL.md` | **Сценарий Диагностики.** Авто-проверка зависимостей, линтеров и `.env` при старте. |
| `.gitignore` | Защита от случайной публикации личных API-ключей, логов и кэша ИИ. |

---

## 🚀 Как использовать на чистой машине

1. Установите актуальную версию [Qwen Code Desktop](https://github.com) и [Git](https://git-scm.com).
2. Скачайте этот репозиторий архивом (**Download ZIP**) и распакуйте в рабочую директорию.
3. Откройте папку проекта в Qwen Code Desktop.
4. При первом запуске агент автоматически прочитает корневой `AGENTS.md`. Он обнаружит отсутствие настроек и самостоятельно развернет глобальный профиль по правильному системному пути Windows:
   `%USERPROFILE%\.qwen\rules\global.md`
5. **Альтернативный шаг:** Если автоматический запуск не сработал, откройте **новый чат** и введите команду:
   *«Прочитай файл rules-Qwen.md и выполни инструкции §1–§5»*.
6. Откройте новый диалог, чтобы агент подтянул созданные глобальные правила и сценарии диагностики из папки `skills/`.

## 🔒 Конфиденциальность и Безопасность
Все файлы репозитория содержат исключительно нейтральные плейсхолдеры (`<USER>`, `email@example.com`). Внесение ваших личных **API-ключей** (Anthropic, DeepSeek, OpenRouter) происходит строго через графический интерфейс (GUI) настроек приложения Qwen. Ключи безопасно сохраняются в системном хранилище Windows (Credential Manager) и никогда не попадают в код репозитория.
