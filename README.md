# 🛠️ Настройка ИИ-агента Qwen Code в один клик

Этот проект создан для автоматической настройки вашего искусственного интеллекта в приложении **Qwen Code Desktop** или **OpenCode**. 

Вам не нужно копаться в скрытых системных папках, создавать файлы или писать код. Умный ИИ-агент сам настроит компьютер за вас в фоновом режиме, включит правила жесткой экономии ваших денег на API-токенах и защитит ваш кошелек от лишних трат.

---

## 🚀 Как запустить автонастройку (Инструкция для новичка)

1. **Скачайте этот проект:** Нажмите зеленую кнопку **`Code`** в правом верхнем углу этой страницы и выберите **`Download ZIP`**. Распакуйте архив в любую удобную папку на компьютере.
2. **Установите программы:** Скачайте и установите две бесплатные утилиты, необходимые для работы (если они у вас еще не установлены):
   * Официальное приложение [Qwen Code Desktop (Скачать версию 0.25.1)](https://github.com)
   * Систему контроля кода [Git (Скачать официальный инсталлятор)](https://git-scm.com)
3. **Откройте проект:** Запустите Qwen Code Desktop, нажмите `File` -> `Open Folder` (Открыть папку) и выберите папку, которую вы только что распаковали из ZIP-архива.
4. **Запустите ИИ:** В правой части экрана откройте окно чата с ИИ и просто напишите любое приветствие (например, *«Привет»*) или нажмите Enter.

**Всё!** Агент прочитает скрытые инструкции, сам откроет терминал, создаст нужные папки Windows и установит глобальные правила. В чате появится сообщение: *«🎉 Всё готово!»*. После этого папку проекта можно закрыть.

## ⚠️ Важное действие после настройки (Ввод API-ключа)

Агент сделает сам абсолютно всё, кроме одного — он не может угадать ваш личный ключ от нейросети. Чтобы ИИ работал в ваших будущих проектах:
1. Зайдите в **Settings** (Настройки) -> вкладка **AI** (или Providers) внутри приложения Qwen.
2. Нажмите кнопку **`+ Connect`** (или *Connect Provider*), выберите вашего провайдера (например, OpenRouter, DeepSeek или Anthropic).
3. Если вы ищете ультрадешёвый или бесплатный тестовый вариант, вы можете использовать агрегатор [GonkaRouter](https://gonkarouter.io). При регистрации они дают стартовый баланс 20 USDT, которого хватит на миллионы токенов. Актуальный список доступных моделей и их точные технические названия (Model ID) смотрите в [Каталоге моделей GonkaRouter](https://gonkarouter.iomodels).
4. Вставьте ваш личный **API Key** в поле настройки.
5. *Ваши ключи шифруются и хранятся внутри системы Windows, они никогда не попадут в интернет или в файлы этого проекта.*

## 💸 Страховка от лишних трат (Лимит токенов)

При работе со своими API-ключами агент может случайно уйти в «петлю отладки» — бесконечно переписывать один и тот же файл, пытаясь исправить скрытый баг, и незаметно тратить ваш баланс.

Поскольку тарифы провайдеров всегда рассчитываются за **1 миллион токенов (1M)**, проще всего установить жесткий лимит на объем одной задачи:
1. Откройте файл настроек: `%APPDATA%\.qwen\settings.json` (в Windows) или `~/.qwen/settings.json` (в Linux/macOS).
2. Внутри блока вашего провайдера добавьте ограничение на объем одной сессии:

```json
"budget": {
  "max_tokens_per_task": 200000,
  "max_tokens_per_session": 500000
}
```

### ❓ Как это выглядит для вас вживую?

Представьте, что вы дали ИИ сложную задачу, но в коде оказалась скрытая ошибка. Агент начинает упрямо переписывать файл снова и снова, тратя ваши токены. Благодаря лимитам, произойдет следующее:

1. **Мягкая остановка:** Как только сумма запросов по этой задаче превысит **200 000 токенов**, ИИ сам нажмет на тормоза, остановит терминал и напишет вам в чат человеческим языком:  
   > *«⚠️ Внимание: я сделал уже 10 попыток исправить код, и мы уперлись в лимит 200K токенов. Чтобы не тратить ваш баланс впустую, я остановился. Напишите "Продолжай", если хотите, чтобы я попробовал другой путь, или "Стоп", чтобы мы разобрались вместе»*.
2. **Жесткая блокировка:** Если вы разрешите продолжить, но робот так и не решит проблему, съев суммарно **500 000 токенов** за день, сработает «красная кнопка». Чат заблокируется, и ИИ выдаст предупреждение:  
   > *«🛑 Критический лимит сессии превышен (500K токенов)! Дальнейшая работа остановлена для защиты вашего кошелька. Пожалуйста, откройте Новый чат, чтобы очистить раздувшуюся память»*.

Это не технический сбой, а встроенная подушка безопасности, которая превращает агента в ответственного ассистента, берегущего ваши деньги.

## 📦 Что внутри (Для продвинутых пользователей)

| Файл / Папка | Что это делает под капотом? |
| :--- | :--- |
| `rules-Qwen.md` | **Канон (Master Prompt).** Главные правила, которые ИИ копирует в систему. Содержит адаптивные профили экономии токенов и протокол умного перехода в новый чат при заполнении памяти. |
| `AGENTS.md` | **Командный центр развертывания.** Тот самый файл, который заставляет ИИ-агента молча настраивать Windows за вас при первом запуске. |
| `skills/` | **Сценарии автоматизации.** Готовые пошаговые инструкции, которые учат ИИ правильно проверять ваш Git (сохранять код без авто-пушей) и проводить диагностику среды (проверять ошибки кода) при открытии новых проектов. |
| `.gitignore` | Защитный щит, который блокирует случайную отправку ваших логов, кэша ИИ или личных заметок на GitHub. |
