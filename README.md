# 🛠️ Настройка ИИ-агента Qwen Code в один клик

Этот проект создан для автоматической настройки вашего искусственного интеллекта в приложении **Qwen Code Desktop** или **OpenCode**. 

Вам не нужно копаться в скрытых системных папках, создавать файлы или писать код. Умный ИИ-агент сам настроит компьютер за вас в фоновом режиме, включит правила жесткой экономии ваших денег на API-токенах и защитит ваш кошелек от лишних трат.

---

## 🚀 Как запустить автонастройку (Инструкция для новичка)

1. **Скачайте этот проект:** Нажмите зеленую кнопку **`Code`** в правом верхнем углу этой страницы и выберите **`Download ZIP`**. Распакуйте архив в любую удобную папку на компьютере.
2. **Установите программу:** Скачайте и установите официальное бесплатное приложение [Qwen Code Desktop](https://github.com) (если оно у вас еще не установлено).
3. **Откройте проект:** Запустите Qwen Code Desktop, нажмите `File` -> `Open Folder` (Открыть папку) и выберите папку, которую вы только что распаковали из ZIP-архива.
4. **Запустите ИИ:** В правой части экрана откройте окно чата с ИИ и просто напишите любое приветствие (например, *«Привет»*) или нажмите Enter.

**Всё!** Агент прочитает скрытые инструкции, сам откроет терминал, создаст нужные папки Windows и установит глобальные правила. В чате появится сообщение: *«🎉 Всё готово!»*. После этого папку проекта можно закрыть.

---

## ⚠️ Важное действие после настройки (Ввод API-ключа)

Агент сделает сам абсолютно всё, кроме одного — он не может угадать ваш личный ключ от нейросети. Чтобы ИИ работал в ваших будущих проектах:
1. Зайдите в **Settings** (Настройки) -> вкладка **AI** (или Providers) внутри приложения Qwen.
2. Нажмите кнопку **`+ Connect`** (или *Connect Provider*), выберите вашего провайдера (например, OpenRouter, DeepSeek или Anthropic) и вставьте ваш личный **API Key**.
3. *Ваши ключи шифруются и хранятся внутри системы Windows, они никогда не попадут в интернет или в файлы этого проекта.*

## 📦 Что внутри (Для продвинутых пользователей)

| Файл / Папка | Что это делает под капотом? |
| :--- | :--- |
| `rules-Qwen.md` | **Канон (Master Prompt).** Главные правила, которые ИИ копирует в систему. Содержит адаптивные профили экономии токенов и протокол умного перехода в новый чат при заполнении памяти. |
| `AGENTS.md` | **Командный центр развертывания.** Тот самый файл, который заставляет ИИ-агента молча настраивать Windows за вас при первом запуске. |
| `skills/` | **Сценарии автоматизации.** Готовые пошаговые инструкции, которые учат ИИ правильно проверять ваш Git (сохранять код без авто-пушей) и проводить диагностику среды (проверять ошибки кода) при открытии новых проектов. |
| `.gitignore` | Защитный щит, который блокирует случайную отправку ваших логов, кэша ИИ или личных заметок на GitHub. |
