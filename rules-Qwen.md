# rules-Qwen.md — Канон настройки Qwen Code

Единый документ переноса конфигурации агента Qwen Code на чистую машину.

## §1. Глобальный QWEN.md (global.md)
Создаётся по пути:
- Windows: `%USERPROFILE%\.qwen\rules\global.md`
- Linux/macOS: `~/.qwen/rules/global.md`

### Секции глобального правила:
1. **Коммуникация:** Лаконичные ответы на русском языке, без приветствий и вступлений. Стиль «senior-разработчик». Пиши кратко, не пересказывай код из diff. Код и комментарии в коде — строго на английском.
2. **Git:** Перед работой проверь `git status`. Фиксируй изменения локально (commit) после каждого логического шага. Remote и push — только по прямой просьбе пользователя.
3. **Python:** Проверяй наличие интерпретатора и виртуального окружения (`.venv`). При отсутствии — предлагай автоматическое создание.
4. **Project Bootstrapping:** В пустой папке уточни стек технологий, создай базовую структуру и локальный файл `QWEN.md`.
5. **README:** Держи `README.md` в актуальном состоянии. Изменил логику — обнови документацию в этом же шаге.
6. **Оболочка Windows:** Терминал Qwen Code — POSIX. Для вызова нативных утилит Windows (например, winget) используй префикс `cmd.exe /c`.
7. **Лимиты и экономия токенов:** См. §1.1.

### §1.1. Лимиты и экономия токенов
#### Адаптивные профили контекстного окна (W)
Определи W (размер окна модели) через команду `/context` или настройки шлюза. Зафиксируй в локальном файле: «Окружение: W = ...K».
- **Узкое (W ≤ 128K):** Чтение файлов частями > 200 строк. Ограничение вывода терминала. Переход в новый чат (handoff) при заполнении окна на 40%.
- **Стандартное (129K < W ≤ 200K):** Чтение частями > 500 строк. Handoff при 65%.
- **Широкое (W > 200K):** Чтение частями > 1000 строк. Handoff при 70%.

#### Пороговые триггеры
- **0.30·W** — Точечный режим: используй `grep`/структуру файлов вместо полного чтения кода.
- **0.55·W** — Запрет на новые подзадачи. Доделывай текущую, пиши чекпоинт-заметку в файл.
- **0.65·W** — Вынужденный Handoff (переход в новый чат).

#### Точечное чтение и Терминал
- Запрещено читать файлы > 500 строк целиком. Используй поиск строк, затем читай диапазоны с лимитом строк.
- Ограничивай вывод терминала: в POSIX используй `| head -50`, в PowerShell — `Select-Object -First 50`. Логи длиннее 500 строк направляй в файл-заметку, не читай в чат.

#### Handoff-протокол
При достижении критического порога контекста:
1. Создай файл `HANDOFF.md` в корне. Пропиши: цель, что сделано (файлы/строки), текущий статус, следующие 3 шага.
2. Выведи сообщение пользователю: «Контекст исчерпан. Пожалуйста, откройте новый чат и введите команду: Прочитай HANDOFF.md и продолжи».
3. После успешного подхвата в новом чате файл `HANDOFF.md` должен быть удален.
