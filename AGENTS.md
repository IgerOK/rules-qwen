## ⚡ Особенности и подводные камни Windows + Qwen Desktop
* **ДВОЙСТВЕННОСТЬ ТЕРМИНАЛА:** Встроенный терминал Qwen Code Desktop является POSIX-совместимым (Git Bash/MSYS2). Он искажает классические Windows-пути (например, превращает `C:\Users\` в `/c/Users/`).
* **ВЫБОР ОБОЛОЧКИ:** Если операция требует работы с файловой системой Windows, реестром или сторонним софтом (вроде `winget`), агент ОБЯЗАН явно вызывать `cmd.exe /c` или `powershell -Command` для выполнения атомарного действия.
* **ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ:** 
  - В командах для нативного Windows-контекста (`cmd`/`PowerShell`) используй синтаксис `%USERPROFILE%` или `%APPDATA%`.
  - Во встроенном POSIX-терминале приложения используй синтаксис `$USERPROFILE` или косую черту `~`.
* **ЭКРАНИРОВАНИЕ:** Любые пути, содержащие пробелы (включая имя пользователя), всегда оборачивай в строгие двойные кавычки `""`.

## ✍️ Конвенции ведения репозитория
* Не дублируй общие глобальные правила (лимиты токенов, стиль речи, handoff) в локальных проектных markdown-файлах. Локальный файл в будущем должен хранить только стек и специфику конкретного проекта.
* **БЕЗОПАСНОСТЬ:** Никакие реальные API-ключи, токены, пароли или секреты не должны попадать в файлы репозитория. Используй исключительно плейсхолдеры (например, `<YOUR_API_KEY>`). Все ключи провайдеров вносятся пользователем только через защищенный GUI-интерфейс настроек приложения.
