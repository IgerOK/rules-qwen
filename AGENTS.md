# AGENTS.md — контекст проекта

## Развёртывание (новая машина)

Если в окружении нет установленных файлов — глобального `~/.qwen/QWEN.md`
или skills в `~/.agents/skills/` — разверни правила из канона
`rules-Qwen.md` §1–§3:

- создай глобальный `~/.qwen/QWEN.md` по §1 (путь зависит от ОС);
- скопируй `skills/*/SKILL.md` → `~/.agents/skills/*/SKILL.md`;
- проверь результат по §5 (создание файлов, доступность skills).

Если установленные файлы уже есть — развёртывание не нужно, только правка
и синхронизация по инварианту ниже.

## Инвариант

Канон-файл `rules-Qwen.md` ↔ установленные файлы (глобальный `QWEN.md`, skills).
Любое изменение правил — сначала в каноне, затем перенос в установленные файлы.

## Смежные репозитории

- [IgerOK/rules-zed](https://github.com/IgerOK/rules-zed) — исходный канон для Zed IDE.
- [IgerOK/zed-free-llm](https://github.com/IgerOK/zed-free-llm) — настройка LLM-провайдера (для Zed).

## Подводные камни Windows

- Терминал Qwen Code — POSIX, искажает Windows-пути. Выбирать cmd или PowerShell,
  где операция короче и надёжнее.
- Пути с пробелами — всегда в кавычках.
- `%USERPROFILE%` вместо `~` в путях для скриптов.

## Конвенции правки

- Правки вносить сначала в `rules-Qwen.md`, затем синхронизировать установленные
  файлы (глобальный `QWEN.md`, skills).
- Не дублировать глобальные правила в проектном `QWEN.md`.
- Секреты в файлы не попадают — только плейсхолдеры.
