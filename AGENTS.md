# 📄 AGENTS.md — Контекст Инфраструктуры Правил (Qwen Code)

## 🚀 Автоматическое развёртывание (Новая Windows-машина)
Если в вашей системе отсутствуют глобальные файлы конфигурации ИИ, выполните следующие шаги:
1. Прочитайте канон-файл `rules-Qwen.md`.
2. Создайте директорию настроек: `%USERPROFILE%\.qwen\rules\` (используя нативный cmd/PowerShell).
3. Скопируйте содержимое раздела §1 из `rules-Qwen.md` и создайте глобальный файл правил по пути `%USERPROFILE%\.qwen\rules\global.md`.

*Если глобальный файл `global.md` уже существует, развертывание пропускается. Выполняется синхронизация по инварианту.*

## 🏛️ Инвариант Системы
* **ЕДИНЫЙ ИСТОЧНИК ИСТИНЫ:** Канон-файл `rules-Qwen.md` ↔ Установленные рабочие файлы.
* **ПОРЯДОК ПРАВКИ:** Любые изменения вносятся СНАЧАЛА в канон-файл `rules-Qwen.md`, и только затем транслируются в глобальный `global.md`.

---

## ⚡ Особенности окружения Windows + Qwen Desktop
* **ДВОЙСТВЕННОСТЬ ТЕРМИНАЛА:** Встроенный терминал Qwen Code является POSIX-совместимым (Git Bash/MSYS2). Он искажает Windows-пути (превращает `C:\` в `/c/`).
* **ВЫБОР ОБОЛОЧКИ:** Для системных операций Windows (работа с реестром, winget, переменные окружения) ИИ обязан явно вызывать `cmd.exe /c` или `powershell -Command`.
* **ЭКРАНИРОВАНИЕ:** Любые пути, содержащие пробелы (включая имя пользователя), всегда оборачивайте в двойные кавычки `""`.
